## 📌 MuMuGuard 使用说明（复制下面这段发群）

**MuMu 模拟器看护面板** — 多开挂机的时候帮你盯住内存和卡顿。

**下载地址**
https://github.com/suuk324/MuMuGuard/releases/latest

下载 `MuMuGuard.exe` 这一个文件就够了，不用安装，双击直接运行。

---

### 第一次运行会被杀软拦，这是正常的

这个程序会结束进程、关闭模拟器，所以容易被 Defender / 360 / 火绒 报毒。程序不联网上传任何数据，除了「检查更新」只访问 GitHub。

遇到拦截图：

| 情况 | 怎么处理 |
|---|---|
| 浏览器提示「已阻止不安全文件」 | 点「保留」→「仍然保留」 |
| 弹出「Windows 已保护你的电脑」 | 点「更多信息」→「仍要运行」 |
| 被杀软直接删掉/隔离 | 把 exe 所在文件夹加入白名单 |

**Windows Defender 加白名单**：
```
设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护
→ 病毒和威胁防护设置 → 管理设置 → 排除项 → 添加或删除文件夹
```

**核对文件完整性**（可选，确认下载没出错）：
在同目录打开 PowerShell，输入：
```powershell
Get-FileHash .\MuMuGuard.exe -Algorithm SHA256
```
和 Release 页面里的 `MuMuGuard.exe.sha256` 对比，一致就是好的。

### 怎么用

1. 双击 `MuMuGuard.exe`
2. 点「详情」看各个模拟器状态
3. 点「启动看护」，之后它自己跑
4. 关掉窗口会缩到托盘，右键托盘图标可以退出

**注意**：如果 MuMu 是「以管理员身份运行」的，面板也要以管理员身份运行，否则重启/休眠模拟器会失败。详情页的「健康检查 → 权限」会提示。

---

### 出问题怎么反馈

点面板右下角 **「导出报告」**，把生成的 txt 发出来就行。

报告里有：实例状态、adb 连接情况、MuMu 路径、系统内存、今天的全部事件。有这些基本能定位到问题。

---

### 支持范围

- 模拟器：MuMu 12 / MuMu 15（安卓 7 ~ 15）
- 系统：Windows 10 / 11
- 多开：1 到 10+ 个都支持
- 内存建议：每个模拟器 6 GB，16 GB 内存建议最多开 2 个

## 📋 常见问题（备用，问到了再发）

**Q：显示「adb 未连接」怎么办？**
A：先等 1~2 分钟。模拟器刚开机的头 30 秒 adb 还没准备好，面板会显示「启动中」。超过 90 秒还是「adb 未连接」，点「导出报告」发出来。

**Q：显示「没有检测到 MuMu 实例」？**
A：打开设置，把「MuMu 安装路径」改成你的实际安装目录（比如 `C:\Program Files\Netease\MuMuPlayer-12.0`）。

**Q：托盘图标找不到？**
A：任务栏右下角的 `^` 里，把图标拖到外面固定住。或者在设置里关掉「启动时进托盘」。

**Q：会不会偷跑流量/上传数据？**
A：不会。除了更新检查（访问 GitHub Releases），没有任何网络请求。源码全部公开，可以自己看。

**Q：能不能开机自启？**
A：设置里可以开。开了之后开机只进托盘，不弹窗口。
