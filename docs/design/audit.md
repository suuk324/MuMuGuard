# 界面体检 · 2026-11-18

对象：MuMuGuard v1.6.3 主界面（1000×700，深色）
方法：hallmark 的 16 条硬底线 + huashu 的「模板装饰」清单，逐条对照代码与截图
截图：`docs/screenshots/ui-now-main.png`

判断标准只有一条：**3 秒内能否看清「哪台在跑 / 哪台在睡 / 谁在等升级 / 谁出问题」。**

---

## 一句话结论

不是配色不好看，是**没有设计系统**：字号 5 档、圆角 3 档、外边距 29 种取值、29 行用 `·` 把不同类型的信息串成一句。
所有卡片长得一模一样，所以信息没有被分出层次。

## 对照 hallmark 的硬底线

命中的条目（原文编号）：

- **#10** 禁止中点连接、禁止箭头粘在文字后 → 命中，29 行
- **#9** 禁止全大写/字距拉开的小标签 → 中文不适用，但“字距拉开”在版本号那行有
- **#11** 禁止卡片套卡片、用 emoji 当图标 → 暂未命中
- **#4** 一个屏幕只讲一件事 → 主界面同时讲实例、内存、健康、事件，密度偏高

---

## 下一版要守住的三条

1. **一眼一条信息**：卡片主行只说状态，副行说对象，时间靠右
2. **只用一个强调色**：绿色 = 正常；操作靠白底黑字，不靠颜色
3. **所有间距从 4 的倍数里选**，差 1px 的字号全部删掉
